# 저스틴 운영실

AI가 반복 업무를 실행하고 대표는 판단과 승인에 집중하도록 만든 회사 위임 운영 앱입니다.

## 현재 기능

- 오늘의 판단·실행·완료 브리핑
- 모든 업무 검색 및 상태 관리
- 외부 실행 전 승인/수정 요청
- 승인 우회 방지 업무 상태 규칙
- 업무 생성부터 승인·완료까지 감사 이력
- 빠른 자연어 업무 위임
- 브라우저 로컬 영속 저장
- 데스크톱·모바일 반응형 UI

## 실행

```bash
npm install
npm run dev
```

## 검증

```bash
npm test
npm run build
```

## 현재 범위

이 버전은 단일 회사·단일 브라우저 MVP입니다. 다음 단계에서 로그인, 조직/사용자, 서버 DB, AI 실행기, 알림을 연결합니다.
